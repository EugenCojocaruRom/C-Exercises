EX\_23NOV - Multiplication Table

Create a program that uses a for loop to print the multiplication table of a number n up to 10 times.



The program should:

&#x20;- Take an integer n as input

&#x20;- Use a for loop to calculate and print n × 1, n × 2, n × 3, n × 4 ...

&#x20;- Each result should be printed on a new line in the format: "n x i = result"
