EX\_08NOV - Compare Two Sprint Times

Two runners finish a sprint. Read the first runner's time on the first line and the second runner's time on the second. Each time is a whole number of hundredths of a second, from 1 to 5000, and a lower time is faster.



Print three lines: whether runner 1 was faster, whether runner 2 was faster, and whether they finished in the same time. Each answer is 1 for true and 0 for false.



Example: For 1250 and 1312:

&#x09;Runner 1 faster: 1

&#x09;Runner 2 faster: 0

&#x09;Same time: 0
