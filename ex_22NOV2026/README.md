EX\_22NOV - Handball Equipment Checkout

Create a program that processes a handball equipment checkout at your community sports center. Read the equipment name, current stock count, number being loaned out, workout intensity (light/moderate/intense), workout duration in minutes, and the equipment's value in dollars.



Calculate the cooldown time needed before next use: light workouts need duration × 0.5 minutes, moderate need duration × 1.0 minutes, and intense need duration × 1.5 minutes.

Calculate the insurance fee as 2% of the equipment value. 

The updated in-stock count is the current stock minus the number loaned out, and the on-loan count is the number loaned out.



Print four lines with the labeled values for the in-stock count, the on-loan count, the cooldown minutes (rounded down), and the insurance fee with 2 decimals.
